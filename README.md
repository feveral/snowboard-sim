# Snowboard Sim

手機單指操控的單板滑雪物理遊戲（Three.js，純靜態，可直接部署 GitHub Pages）。

## 操控（單手）
在螢幕任何地方按住拖曳：
- **左右**：立刃角度（Heel / Toe），拖越遠刃越立，放開＝板子放平
- **往下拉**：用身體甩板（搓雪、煞車、hockey stop）
- **往上推**：壓低身體，減少風阻

電腦：← → 立刃（Shift 小角度）、↓ 甩板、↑ 壓低

## 物理模型（`src/physics.js`）
- **Carve 轉彎半徑**：`R = max(側切半徑 7.8m × cosθ, v² / (g·tanθ + 指向彎心的重力分量))`，騎手的傾斜要和刃角平衡
- **甩板**：身體轉板子的角速度，板子轉到跟前進方向約 90° 時自然停（hockey stop）
- **刃的抓力**：刃能承受的側向力比 ≈ `tan(θ + φ)`，φ 是雪面抓力角（壓雪道 11°、冰面 3°、野雪 15°）；超過就側滑
- **判定**依滑移角 β（板頭方向 vs 前進方向）：Carving < 3.5° ／ 半刻滑 3.5–10° ／ 搓雪 10–35° ／ 掃雪・推坡 > 35°
- 逆刃（往立起來的那個刃方向側滑）、撞樹、落地歪或太重會摔倒
- 風阻、滑行摩擦、地形起伏、天然跳台、騰空

## 地圖（`src/terrain.js`）
無限往下延伸的程序化山坡：坡度 12°–26° 變化、蜿蜒雪道、雙側上升的谷地、rollers、冰面、野雪 mogul、樹林、每 140m 一個跳台，加上飄雪。

## 開發
```bash
python3 -m http.server   # 開 http://localhost:8000
npm run sim              # 無畫面的物理測試（腳本騎手跑各種情境）
```

## 部署
Settings → Pages → Source 選 `Deploy from a branch`，branch `main`、資料夾 `/ (root)`。
