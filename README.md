# Snowboard Sim

手機單指操控的單板滑雪物理遊戲（Three.js，純靜態，可直接部署 GitHub Pages）。

## 操控（單手，方向都相對畫面）
在螢幕任何地方按住拖曳：
- **左右**：往畫面左/右轉，拖越遠刃越立（自動選前刃/後刃，反腳 switch 也不會左右顛倒）
- **往下拉**：煞車推坡，拉越多板子越橫；下拉時偏右＝前刃推坡、偏左＝後刃推坡（regular）
- **往下拉＋左右拉到底**：板子平放持續轉（地面 180／360），轉過 90° 放開就換腳（Switch），heel→heel、toe→toe 換腳
- **放開**：板子對齊比較近的那一端（板頭或板尾），變直板往前滑
- **往上推**：壓低身體，減少風阻；**快速往上一撥 = Ollie**
- **空中**：左右 = 轉體，往下拉 = 抓板（落地前放開）

右上角：🎥 視角（高/中/近）、🔊 聲音、? 說明、↺ 重來。電腦：← → 轉彎（Shift 小角度）、↓ 煞車、↑ 壓低

## 玩法
每個彎都會評分（Clean / Deep / Euro Carve、半刻滑、搓雪），乾淨的 carve 彎、穿過旗門、跳台騰空與空中轉體會累積 combo（最多 ×4）；搓雪轉彎、漏旗門、摔倒會中斷 combo。進入支線雪道有獎勵，最佳分數存在瀏覽器。

## 公園 Terrain Park
每 2.1km（第一個在 560m）一個公園：小跳台線 S/M、大跳台線 M/L/XL（tabletop：拋物線起跳台、平台、knuckle、落地坡）、兩個 ride-on box、rollers。轉體（FS/BS 180/360…）、抓板、Ollie、50-50 / Boardslide 都會計分，電腦滑雪者也會進公園跳（有的會轉、會抓板）。`npm run park` 跑跳台物理測試。

## 物理模型（`src/physics.js`，力學版 v2）
- **加速度來自重力**：重力沿坡面的分量，扣掉雪面摩擦（速度越快摩擦越小）、風阻（壓低時較小）、以及橫滑時推雪的阻力（≈ k·v橫²，所以 hockey stop 先猛後緩）
- **負重**：N = g·cos(坡度) + v²·κ（沿前進方向的地形曲率）。凹地被壓、過坡頂變輕；刃的抓力、摩擦都乘上 N
- **板子是有轉動慣性的剛體**：咬住的刃把板子帶往側切／平衡弧線 `R = max(Rsc·cosθ, v²/(N·tanθ + g向心))`；身體的扭力（甩板、煞車、低速轉向、滑完回正）有上限，刃咬越深、負重越大越難扭
- **側向力是滑移曲線**（類似輪胎模型）：隨滑移角上升到 `N·tan(θ+φ)`（雪的剪力上限 ≈ 2g），之後降到動摩擦。carving 自然穩定在 1–3° 滑移角，要求超過就洗出去變搓雪
- **平衡**：能立的刃角 ≤ atan(當下側向力/負重) + 膝髖折疊角度，所以刃角會隨著彎建立起來，慢速沒辦法深立刃
- **空中**：起跳時的轉動會保留，手指可以加轉；放開會減速轉體（看輔助程度）
- **判定**依滑移角 β：Carving < 3.5° ／ 半刻滑 3.5–10° ／ 搓雪 10–35° ／ 掃雪・推坡 > 35°
- 逆刃、撞樹、落地歪或太重會摔倒；**物理輔助**（高／中／低）調整自動回正、逆刃容錯、轉體停止、落地角度容錯、立刃餘裕

## 世界
- `src/terrain.js`：無限往下延伸的山。主雪道蜿蜒、每 640m 分出一條支線（蘑菇坡黑線／林間道／陡坡）再匯回，每 700m 一段陡坡、rollers、冰面、野雪、樹林、石頭、天然跳台、旗門、纜車線、山屋
- `src/env.js`：遠山、雲、天空，時間會從早晨→午間→黃昏變化，天氣在晴／小雪／大雪起霧間切換；雪面有壓雪紋、閃光雪晶、冰面反光
- `src/fx.js`：雪痕（立刃刻痕＋板底依接觸面積留下的痕跡，直滑窄、搓雪寬）、噴雪
- `src/riderModel.js`：有側切的雪板、雙板、IK 關節的人物（布料紋理、頭盔護目鏡、脖圍、背包），身體傾斜依側向 G 平衡
- `src/npc.js`：電腦控制的單板／雙板滑雪者（carver、racer、新手搓雪…），用跟玩家一樣的物理，會避樹、避開玩家、走支線，撞到人會一起摔
- 雪煙：搓雪、hockey stop、深 carve、粉雪、落地都會揚起會擴散飄散的粉雪煙霧；下雪是世界座標的雪花（會飄、會轉、近鏡頭的大雪花失焦），越騎越快雪會迎面而來
- `src/audio.js`：風聲、carving 嘶聲、搓雪刮聲、落地聲

## 開發
```bash
python3 -m http.server   # 開 http://localhost:8000
npm run sim              # 無畫面的物理測試（腳本騎手跑各種情境）
```

## 部署
Settings → Pages → Source 選 `Deploy from a branch`，branch `main`、資料夾 `/ (root)`。
