物理輔助

輔助越低：滑完不會自動擺正、反刃比較容易摔、空中轉體不會幫你停、落地角度要更準、能立的刃更依賴平衡。

怎麼玩

手勢

左右：往畫面左/右轉。拖越遠刃越立、轉越急。遊戲會自動判斷該用前刃還是後刃，反腳（switch）也不會左右顛倒。
往下拉：煞車。板子橫過來、用上坡那側的刃刮雪；拉一點是搓雪減速，拉到底是 hockey stop。
往下拉 + 偏右：板頭往右甩 → 前刃推坡（regular）；偏左 → 後刃推坡。
換前進腳，兩種做法：① 邊滑邊轉：往下拉一點（不用拉到底）＋左右拉到底並按住，板子會放平、不刮雪，邊往下滑邊轉，速度幾乎不掉，地面 180 約 1.5 秒；② 跳轉 180：手指往左/右拉著的同時快速往上一撥（Ollie），身體會帶著板子轉，轉過 90° 就可以放開，會自動對準落地。轉過 90° 之後放開，原本的板尾就變成板頭、換另一隻腳在前（反腳 Switch）——heel 轉 heel、toe 轉 toe 就是這樣做：先放平換刃，下拉＋拉到底轉 180，放開後繼續用同一側的刃轉彎。
放開：板子會對齊比較近的那一端（板頭或板尾），不會硬拉回原本的方向。停在坡上放開，會轉向山下開始滑。
往上推：壓低身體減少風阻。
快速往上一撥：Ollie 起跳。在跳台唇口撥，可以跳更高。
空中：左右 = 轉體（180/360/540…），放開後會保持轉動並對準最近的板頭或板尾落地；往下拉 = 抓板（Indy、Melon…），落地前記得放開。

公園 Terrain Park

從起點往下約 560m（之後每 2.1km 一個）。右邊是小跳台線（S/M），左邊是大跳台線（M/L/XL），藍線是唇口、橘色標記是桌面盡頭；最後有兩個可以直接滑上去的 Box（板子直 = 50-50，往下拉讓板子橫 = Boardslide）和一段 rollers。大跳台約 45–60 km/h 進去剛好。

滑行判定（滑移角 = 板頭方向 vs 前進方向）

Carving 刻滑 < 3.5°，只靠刃轉彎，雪上留下細細的刻痕
半刻滑 3.5–10°，或轉彎有一部分靠甩板
搓雪 10–35°，板子刮出寬的刮痕
推坡 / 掃雪 > 35°，板子橫著刮

計分

每個彎都會評分：乾淨的 carve 彎加分又累積 combo（最多 ×4），立刃越深、G 越大分越高；穿過旗門（紅/藍旗中間）、跳台騰空、空中轉體都加分；搓雪轉彎、漏旗門、摔倒會中斷 combo。進入支線雪道（蘑菇坡、林間道、陡坡）有獎勵。

物理

• 速度靠重力沿坡面的分量，扣掉雪的摩擦（越快越小）、風阻、橫滑時推雪的阻力
• 負重 = 重力 + 地形彎曲：凹地被壓、過坡頂變輕（看「負重」數值），刃的抓力跟著變
• 板子有轉動慣性：刃咬住時沿著側切弧線轉，入彎要時間建立 G；刃的側向力像輪胎，滑移角 1–3° 是 carving，要太多就洗出去變搓雪
• 能立多少刃要看平衡：有速度、有側向力才能深立刃，慢速硬立不上去
• 刃能吃住的側向力 ≈ tan(刃角 + 雪的抓力角)，上限約 2g；冰面（偏藍、反光）更差
• 往立起來的刃那側側滑 → 逆刃摔倒；跳台落地要對準前進方向
• 電腦：← → 轉彎（Shift 小角度）、↓ 煞車、↑ 壓低
